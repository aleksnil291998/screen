📱 Трансляция экрана Android

Как начать трансляцию:

  1. Установите на Android приложение для скринкаста (рекомендуется Screen Stream Mirroring или используйте наш пример кода)
  2. Введите уникальный ID трансляции выше
  3. Нажмите кнопку "Смотреть трансляцию"
  4. Запустите трансляцию на Android устройстве

Рекомендуемое приложение: Screen Stream Mirroring
